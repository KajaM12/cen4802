CEN 4802 ToDo List Application

Author: Kaja Moore

Description:

This project is a Java-based ToDo web application developed for CEN 4802. The application allows users to manage a list of tasks through a web interface.

The project will be used throughout the course to demonstrate software development and DevOps practices, including version control, feature development, testing, and deployment.

Technologies
Java
Maven
JSP
Java Servlets
Hibernate/JPA
MySQL
Apache Tomcat 9
Git
GitHub
Current Functionality

The initial version of the application allows users to:

Add ToDo items
View ToDo items
Delete ToDo items

Additional functionality will be developed throughout the course.
